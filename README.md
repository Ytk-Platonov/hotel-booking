# Сервис бронирования «Светлые Сны»

## Описание
Веб-сервис для бронирования номеров в гостинице. Реализовано в рамках Задания 4 ГИА ДЭ БУ.

## Функционал
### Гость:
- Просмотр каталога номеров с фильтрацией по категориям
- Бронирование номера с валидацией дат
- Автоматическая блокировка занятых периодов

### Администратор:
- Вход по логину/паролю (hotel123 / adminHotel)
- Просмотр списка заявок
- Одобрение или удаление заявок

## Технологии
- PHP 8.x (PDO)
- MySQL 8.x
- Bootstrap 5.3.2
- jQuery 3.7.1 + jQuery Inputmask
- HTML5, CSS3

## Установка
1. Импортировать `database.sql` в MySQL
2. Сгенерировать хеш пароля через `hash.php` и обновить SQL
3. Настроить `config/db.php`
4. Разместить изображения номеров в `assets/images/`
5. Загрузить на веб-сервер

## Структура
- `index.php` — каталог с фильтрацией
- `order.php` — бронирование с календарём
- `login.php` — вход администратора
- `admin.php` — панель управления
- `logout.php` — выход из системы
